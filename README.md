# Gen_AI
A hands-on learning repository exploring Generative AI concepts through practical projects and experiments. Covers LLMs, prompt engineering, Ollama, LangChain, structured outputs, Pydantic, RAG, embeddings, vector databases, LangGraph, and AI agents — progressing from fundamentals to end-to-end GenAI applications.

# Generative AI Learning Journey 🚀

This repository contains my hands-on learning journey in Generative AI.

The goal of this repository is to understand GenAI concepts by building
practical projects rather than only studying the theory.

## 📚 Topics Covered

- Large Language Models (LLMs)
- Prompt Engineering
- Ollama
- Local LLMs
- LangChain
- Structured Output
- Pydantic
- Output Parsers
- Embeddings
- Vector Databases
- Retrieval Augmented Generation (RAG)
- LangGraph
- AI Agents
- Agentic AI
- Streamlit
- End-to-End GenAI Applications

## 🛠️ Approach

Each concept is explored through small, practical projects that
demonstrate how the technology works and how different GenAI
components can be combined to build real-world applications.

## 🎯 Goal

Build a strong practical foundation in Generative AI and gradually
progress from basic LLM applications to RAG-based systems,
agentic workflows, and production-oriented AI applications.
